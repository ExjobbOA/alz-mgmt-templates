# Tests (utvärderingsevidens)

Det här är exjobbets utvärderingsevidens: testscenarierna T1 till T10, kopplade till kriterierna
K1 till K11. Det är inte en körbar testsvit, utan dokumentation av hur plattformen utvärderades.

Evidensen utfördes mot en numera avvecklad testtenant och refererar det ursprungliga repo-namnet
`alz-mgmt-oskar` (nu `alz-mgmt`). Tenant-GUID:n, länkar och skärmbilder är därför historiska och
speglar inte det överlämnade läget.
